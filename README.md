# Mapa electoral · Generals 2023 per secció censal

Mapa interactiu d'accés restringit. Les dades (`dades/*.bin`) estan xifrades amb AES-256-GCM
i només es poden llegir des de la pàgina introduint la contrasenya.

- `index.html`: la pàgina (Leaflet 1.9.4).
- `dades/seccions_2023.bin`: seccions censals (ICGC/Idescat, 1-1-2024) amb els resultats, xifrades.
- `dades/limits.bin`: límits municipals i provincials, xifrats.

Fonts: resultats electorals per secció; límits de seccions censals de l'ICGC i l'Idescat. Mapa base © ICGC (CC BY 4.0) i © OpenStreetMap.
